# 验收样本（Claude 维护，Codex 只读）

```bash
cd snore-log/fixtures
python3 gen.py                  # 生成 15 个合成样本，约 40 秒、460 MB（out/ 已 gitignore）
python3 check.py --reference    # Claude 自检：参考实现跑样本，应 18/18 通过
python3 check.py --codex        # 验收 Codex：假分类器 + 期望值 + 分块一致性（120 秒、7 秒）
python3 check.py --real         # 真实苹果分类器，只打印不判分
```

全程只写文件、不播放声音（`say -o` 输出到文件）。

## 文件

| 路径 | 内容 |
|---|---|
| `gen.py` | 合成器：底噪 30 dB、鼾声（70–110 Hz 谐波+颤动，约 52 dB，每 4 秒一声）、大喘 64 dB、呼吸、咳嗽、关门、闹钟、风扇、电视语音（系统 Tingting 语音） |
| `reference.py` | R1–R10 的参考实现（不含留存池），口径 = `docs/codex-handoff-01-core.md` 补充 A |
| `check.py` | 对照脚本 |
| `cases/<id>.json` | 场景说明、运行参数、期望值（含容差） |
| `labels/<id>.labels.json` | 假分类器标注 `{"snoring":[...], "breathing":[...]}`，按**文件秒**对齐 |

## 场景

| 编号 | 考什么 |
|---|---|
| 01 | 基本停顿：打呼→安静 15 秒→大喘 |
| 02 | 安静 5 分钟后又打呼 → 超过 90 秒不算停顿 |
| 03 | 安静 9 秒 → 不算停顿，但拆成两段 |
| 04 | 安静后没有大喘、直接接着打呼 → 恢复方式 resumeSnore |
| 05 | 中途开风扇，噪声底 30→45 dB；风扇下打呼和停顿 |
| 06 | 电视说话，句间停顿后大声说话 → 不打呼就不能算停顿 |
| 07 | 咳嗽、关门不拉高打呼 P95；不打呼 2 分钟后关门不算停顿 |
| 07b | **已知误报**：打呼停 12 秒后关门 → 规则会算 1 次。用来确认按文档执行 |
| 08 | 停顿跨第 120 秒分段边界 |
| 09 | 只有呼吸声 → 0 打呼 0 停顿 |
| 10 | 来电中断 60 秒 + 闹钟：中断不能当安静拼起来，闹钟后不计 |
| 11 | 只 1 次但 32 秒 → 健康提示 |
| 12 | 18 次/小时 → 健康提示；另跑「延迟 10 分钟」只算后 3 次；闹钟切在大喘那一秒 → 不确认；中断 120 秒后的安静不沿用中断前的打呼 |
| 13 | 4 次/小时 → 不提示 |
| 14 | 90 分钟组合夜：留存池 ≤12 且 7 个停顿段全留；4.7 次/小时差一点不提示 |

## 已知局限（2026-11-05 实测）

- **苹果分类器把合成鼾声认成 music**（snoring 置信度约 0.01），电视语音能正确认成 speech（0.8 左右）。
  所以合成样本只能验证**规则层**，打呼识别准不准必须用**真实录音**（用户用语音备忘录录的夜间录音）。
- 开头几秒噪声底还没建立，那几秒的鼾声不算打呼（01 的最长连续打呼因此是 ~175 秒而不是 180 秒）。正常使用有 10 分钟延迟，不影响。

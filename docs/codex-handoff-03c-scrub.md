# Codex 交接 03c：片段播放可以拖进度条

> 03b 已验收并装机，用户真机确认放大后能听清（2026-11-07）。用户新需求：**播放进度条可以拖动**。
> 写入范围：`ios/` + `docs/codex-handoff-03c-results.md`。不联网、不加依赖、不 git commit。命令加 `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`。

## 要做的

1. **进度条改成可拖的 `Slider`**，两端显示「当前时间 / 总长」（`0:42 / 2:00`）。
   - 播放中拖动：拖的时候暂停刷新进度（别让定时器把滑块拽回去），松手后跳到该位置继续播。
   - 没在播放时也能拖：先选好位置，再点播放就从那里开始。
   - 跳转用 `AVAudioPlayer.currentTime`（播的是放大后的临时文件，原文件不动，这点不变）。
2. **±10 秒按钮**（后退 10 秒 / 前进 10 秒），夜里睡眼惺忪拖不准时用。
3. **在进度条上标出「这段为什么被留下」的位置**，这是让拖动真正有用的部分：
   - 疑似停顿片段：在停顿开始处画一个红色小刻度，旁边一个「跳到停顿」按钮，跳到停顿开始前 5 秒（这样能先听到停之前的鼾声）。
   - 很响片段：标出这段里最响那一秒。
   - 最长连续打呼片段：不标。
   - 位置 = 事件在整晚的秒数 − 片段起点秒数（片段起点 = 首个段号 × 120，跨段合并的片段按合并后的起点算）。超出片段范围的不画。
4. 同一时间只有一段在播；切到另一段时，上一段的滑块复位。
